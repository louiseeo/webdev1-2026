My Web Dev Journey

Week 1: Learning the Basics of HTML

Published on: June 09, 2026

Today, I started learning the basics of HTML and discovered how web pages are created. At first, the different tags and elements seemed confusing because I am not familiar with it, but as I followed our instructor's instruction, I began to understand how they work together to organize content on a webpage. I learned how to create headings, paragraphs, insert images, and add links.

As I continued working on the simple project portfolio we are working on, I felt my confidence slightly improve while using HTML. It was exciting to see my code turn into a simple webpage that I could view in a browser. This experience helped me appreciate the importance of HTML in web development and motivated me to keep learning more about creating websites.

"Small steps especially in coding can make a difference"
