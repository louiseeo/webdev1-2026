My Development Showcases

Project 1: UnderCoven Game

UnderCoven is a real-time, terminal-based multiplayer game where players connect to a central server and try to identify the hidden Imposter player among them. In each game, all players are secretly given the same word, while the imposter player receives a similar but different decoy word. Players take turns giving one-word clues, then vote to eliminate who they believe is the outsider. The Imposter wins by blending in; the others win by catching the imposter.

Project 2: Rock Paper Scissors Game

This project is a simple Rock Paper Scissors game created using Java and played in the terminal. The user chooses between Rock, Paper, or Scissors, while the computer randomly generates its own choice. The program then compares both choices and displays the result, showing whether the user wins, loses, or draws. This project demonstrates basic Java concepts such as user input, conditional statements, loops, and random number generation in a fun and interactive way.

Project 4: Java Calendar Console Application (Calendar API Project)

This project is a simple Java console-based calendar application that allows the user to view a monthly calendar by entering a specific year and month. The program uses Java’s built-in GregorianCalendar and Calendar classes to calculate the starting day of the month and the number of days in that month.

Project 5: Client-Server Hangman Game

This project is a client-server based Hangman game developed in Java where multiple players can connect to a server to play interactively. The system includes a login and sign-up feature, allowing users to create accounts and securely access the game. Players can also choose different difficulty levels, which affect how challenging the word guessing will be.
